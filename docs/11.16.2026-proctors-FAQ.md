## Lab 1: What are the evaluations actually testing?

**The local release-gate scoring is deterministic:** given the same agent responses and case data, `src/evaluate.py` computes the same scores using Python checks, not an AI judge. The agent responses themselves, including the reviewer's verdict, can vary between runs, so a rerun is not guaranteed to produce the same scores.

The script runs 14 alerts against the expected dispositions in `data/golden.jsonl`. Thresholds come from `evals/thresholds.json`:

| Check | What the code tests | Required | Blocks release? |
| --- | --- | --- | --- |
| `disposition_accuracy` | Exact match between the triage disposition and the golden answer: `escalate`, `close_false_positive`, or `request_info`. | At least 85%: 12 of 14 alerts | Yes |
| `escalation_recall` | Of the seven alerts whose golden answer is `escalate`, how many the triage agent escalated. | 100%: all seven | Yes |
| `citation_validity` | Each alert's triage reasons contain at least one recognized citation ID, and every recognized ID exists in that alert's case data or the screening lists. | 100%: all 14 alerts | Yes |
| `reviewer_agreement` | How many reviewer responses have verdict `agree`. The code counts that verdict; it does not judge the reviewer's reasoning. | At least 70%: 10 of 14 alerts | No |

**Important limits:** Citation validity checks that IDs exist, not that the cited evidence supports the recommendation. Reviewer agreement is not correctness: both agents can agree on the wrong answer. The golden file also contains expected priorities, but these four checks do not score priority. A Prompt Shields block on a golden alert also makes the local gate fail.

**Foundry Task adherence is separate and is not deterministic scoring.** With `--foundry`, the script additionally starts a direct `triage` evaluation using Foundry's built-in AI judge to assess whether the response follows the task instructions. That judge's result is viewed in Foundry; it is not one of the four local gate metrics and does not determine the local **PASS/FAIL**.

For a participant's failed local gate, open the terminal's **Evidence Pack** path and inspect `report.md`: it lists each metric against its threshold and each alert's expected and recommended disposition, reviewer verdict, and invalid citations. Do not treat a Foundry score or reviewer agreement as a substitute for these checks.
